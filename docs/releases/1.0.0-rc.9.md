# Termy 1.0.0-rc.9

Release candidate prepared from the changes since `v1.0.0-rc.8`.

## Before upgrading persistent sessions

If you use `multiplexer_enabled = true`, finish or save your work in existing
persistent terminal sessions before upgrading. Quitting the app alone leaves
these sessions running.

This candidate uses session-host protocol version 4. An rc.8 host speaks
version 3, so the new version cannot attach to its terminals. Termy now
detects this, keeps the affected tabs open as "Session ended", and falls back
to regular terminals with a toast. Run `termy mux shutdown` (from either
version) to stop the old host and its remaining terminal processes; rc.9 can
stop a host of any protocol version. If a host hangs, `termy mux shutdown
--force` stops it by its recorded process ID.

## Changes

### Persistent sessions

- The session host owns the session layout, with revisions and validation,
  so edits from several windows and the `termy mux` CLI no longer overwrite
  each other.
- Tabs recover from host errors, timeouts and lost connections instead of
  closing, and reconnect to a new host when the old one is gone.
- Remote rendering sends only changed rows and caches images on both ends;
  hidden tabs pause their frame stream.
- Shell-integration events are delivered in order and reattached tabs no
  longer restart command timers or replay stale progress.
- Clipboard (OSC 52) requests are answered asynchronously without stalling
  the terminal.
- Reopen a detached window from the command palette or the Window menu.
- The host runs isolated from the app that launched it, with a private
  rotating log and a hardened session directory on Unix and Windows.

### `termy mux` CLI

- `capture` and `wait` read the host's lines, join wrapped rows, reach
  history, and report exited, closed or lost output with distinct codes.
- `send --wait` and `wait --after` match only the output of the sent input.
- `key` accepts names in any case, aliases, chords and several keys at once.
- `create` loads the user's config and shell integration;
  `--working-directory` resolves against the caller's directory.

### Performance

- Grapheme-heavy output parses about 20-25% faster.

## Testing this candidate

Try persistent sessions across several windows, detaching and reopening a
window, and scripting a session with `termy mux`. Report the operating
system, architecture, and reproduction steps with any issue.

This is a pre-release. The publication workflow must mark it as such so stable
release finalization and AUR publication do not run.
