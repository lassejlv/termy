## Pick the correct layer

| Change | Owning layer |
| --- | --- |
| Terminal parsing, PTY, frames, input, search | `termy_core` |
| C, Swift, or Objective-C integration | `termy_core::ffi` |
| Shared tabs, panes, and terminal UI behavior | `termy::terminal_ui` |
| GPUI desktop application | `termy` |
