The tour shows once after you install or update to 0.3.0. Open it again any time from **Help → Welcome Tour**. Each page has a small animated preview, and some have a switch so you can try the feature straight away.

## The pages

1. **Termy Next.** Programs run in Termy's session host, so quitting only detaches.
2. **A window shows a session.** A session is a named group of tabs, one per window. Close a window and its session waits in the switcher.
3. **Split, float and zoom.** Every tab is a split layout of panes. Drag a pane's header to move it, float one above the rest, or zoom it to fill the tab.
4. **Everything is one search away.** Commands, tabs, sessions, tasks and plugin actions share one palette, with each shortcut next to its command.
5. **See what your agents are doing.** Switch on notifications for programs that need you.
6. **Completions under the prompt.** Switch on the zsh plugin for new panes.
7. **Bring your own commands.** Switch Rex plugin loading on or off.
8. **termy, from any shell.** Install the `termy` command.
9. **Make it yours.** Pick or import a theme, and choose the Liquid or Classic interface.

Choose **Skip** to close the tour. Everything it turns on can be changed later in Settings.
