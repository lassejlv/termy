# Termy 1.0.0-rc.12

Release candidate prepared from the changes since `v1.0.0-rc.11`.

## Changes

### macOS packaging and permissions

- The macOS app bundle now declares Bluetooth and microphone usage descriptions
  and ships default entitlements (`scripts/macos/termy.entitlements`), so CLI
  tools and agents running inside Termy can request access instead of being
  denied by macOS.

### Terminal engine, multiplexer, and performance

- Reduced idle and active CPU usage in the custom terminal backend by avoiding
  unnecessary wakeups for unseen panes while continuing to deliver titles,
  OSC 7501 program status, and process exit events.
- Frame updates carry scroll deltas instead of full-screen damage, and
  `engine_ffi` history reads avoid leaving scrollback unpacked in memory.
- Recorded OSC 133 prompt marks (`A` and `C`) on terminal rows (preserving them
  through history and reflow) and exposed them through the multiplexer and C
  ABI.
- Mouse motion now uses the half-backlog path so it cannot starve keyboard
  input, and keyboard handling fixes Return/Tab after dead keys, Kitty key
  releases, keypad key identities, and selection tracking.

### Cleanup and reliability

- Removed the retired `crates/relay` server now that mobile connections run
  directly over Tailscale.
- Fixed Rust 1.100 Clippy lints across crates and stabilized a timing-sensitive
  session test.

## Testing this candidate

Try running CLI tools that request macOS microphone or Bluetooth permissions,
heavy scrolling output, and mouse motion alongside keyboard input. Report the
operating system, architecture, and reproduction steps with any issue.

This is a pre-release. The publication workflow must mark it as such so stable
release finalization and AUR publication do not run.
