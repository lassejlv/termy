# Termy 1.0.0-rc.11

Release candidate prepared from the changes since `v1.0.0-rc.10`.

## Changes

### Security

- Bracketed paste no longer lets pasted text form its own end marker. Stripping
  an inner `ESC[201~` could join the bytes around it into a new one, so a
  crafted clipboard or file drop could end the paste early and run the rest
  without Enter.
- Hovering a link with the link modifier held no longer touches the
  filesystem for network paths, so text a program prints can't reach an SMB
  share or a slow mount just by being hovered.
- Kitty graphics local-file, temporary-file and shared-memory uploads are
  stricter about what they read and unlink, since the request can come from
  any program, including one on the far side of SSH.
- OSC 133 shell-integration marks (and other OSC 133x/1337 commands) are held
  to the normal string limit instead of the 256 MiB file-transfer limit.
- Plugin docs and Settings now say plainly that plugins run with your full
  user account access. Capabilities pick which Termy APIs a plugin gets; they
  are not a sandbox.

### tmux

- Terminal queries in tmux panes are answered once. Termy no longer sends its
  own reply after tmux's, which showed up as stray `^[[?62;22c` text.
- Programs that turn off `ONLCR` (vim, curses in `nonl` mode) keep their
  cursor column in live tmux output.
- Non-UTF-8 output and paths no longer end tmux control mode or break the
  window and pane snapshot.
- A command containing `#` or an open quote no longer stalls the tmux control
  session.
- Panes keep their render caches across tmux snapshots, so typing in tmux
  mode no longer reshapes every row and reuploads images.

### Kitty graphics

- When the image quota is full, the oldest placed images are evicted instead
  of every later upload failing, so long `icat` or Yazi sessions keep showing
  images.
- Images inside synchronized updates (Yazi previews, for one) decode off the
  engine lock, and placements at the cap are evicted in constant time, so
  heavy image output no longer stalls rendering and input.

### Plugins

- One broken plugin is skipped during discovery instead of disabling every
  plugin.
- Plugins whose dotted command or view IDs happen to coincide keep loading.
- Plugin secrets are cached instead of read from the OS keychain on every
  request, avoiding repeated unlock prompts on Linux.

### Install CLI

- For bash on macOS, the PATH block goes into the profile bash actually
  reads, so a new `~/.bash_profile` no longer hides `~/.profile` or
  `~/.bash_login`.
- Shell profiles keep their permissions, owner, links and extended attributes
  when the PATH block is added.

### Windows and tabs

- With the Built-in Multiplexer, closing a window's last tab closes the
  window, and native tabs closed from the tab bar don't come back.
- On macOS with "Prefer tabs when opening documents: Always", Cmd+N opens a
  new window instead of a tab.
- Long non-ASCII link previews no longer crash the app.

## Testing this candidate

Try pasting into programs that use bracketed paste, tmux mode with vim and
Yazi image previews, Install CLI for bash on macOS, and closing tabs and
windows with the Built-in Multiplexer. Report the operating system,
architecture, and reproduction steps with any issue.

This is a pre-release. The publication workflow must mark it as such so stable
release finalization and AUR publication do not run.
