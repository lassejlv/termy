## Change a shortcut

**Settings → Keyboard** lists every command. Click a shortcut and press the new keys: ⌫ removes it, Esc keeps it. A key another command uses moves after you confirm. Menus, the palette and the welcome tour show the keys as you set them.

Bindings from `termy.bind` in your [plugin config](/docs/plugins), including sequences like `ctrl+b>c`, come before these.

## Defaults

| Action | Keys |
| --- | --- |
| Command palette | ⇧⌘P |
| Change session | ⌘K |
| New session | ⇧⌘N |
| New tab | ⌘T |
| New window | ⌘N |
| Go to directory | ⇧⌘G |
| Split right / down | ⌘D / ⇧⌘D |
| Split left / up | ⇧⌘← / ⇧⌘↑ |
| Split best fit | ⌘↩ |
| Float pane | ⌥⌘↩ |
| Zoom pane | ⇧⌘↩ |
| Focus pane | ⌥⌘ + arrows |
| Previous / next pane | ⌘[ / ⌘] |
| Move pane | ⌥⇧⌘ + arrows |
| Next / previous tab | ⌃⇥ / ⌃⇧⇥ |
| Show tab 1–8 / last tab | ⌘1…⌘8 / ⌘9 |
| Move tab | ⌃⇧⇞ / ⌃⇧⇟ |
| Close pane / tab / window | ⌘W / ⌥⌘W / ⇧⌘W |
| Toggle sidebar | ⌘/ |
| Toggle activity | ⌘. |
| Command box | ⇧⌘E |
| Font size | ⌘+ / ⌘− / ⌘0 |
| Clear scrollback | ⌥⌘K |
| Insert path | ⌃⌘I |

## On the shell line

⌘← and ⌘→ move to the start or end of the shell line, and ⌘⌫ deletes it.
